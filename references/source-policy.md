# 法律来源与时间适用政策

## 来源顺序

1. 全国人大及其常委会、国务院、最高人民法院、人力资源和社会保障部门等发布机关。
2. 国家法律法规数据库、人民法院案例库等官方数据库。
3. 用户合法授权的北大法宝等专业数据库 MCP/API，用于版本沿革和交叉核验。
4. 权威二手资料只作线索，不单独支撑现行效力结论。

每条法律依据记录名称、条款、版本、效力期间、官方链接和检索时间。网络不可用时保留证据分析，但不得凭模型记忆填充已核验状态。

## 时间适用

先确定要件对应的法律事实，再选择当时有效的规则：劳动关系建立、工资或加班发生、解除通知到达、竞业限制履行等可能对应不同日期。文书形成、案件受理或报告生成时间不能替代相关法律事实日期。存在溯及力、衔接规则或司法解释时间效力问题时，单独列为待确认并说明依据。

## MCP 边界

MCP/API 是 Agent 的可选取证工具，不是确定性 Python 管线的运行依赖。不得保存账号、密码、Cookie 或 Token，不得绕过登录、验证码或付费权限。
