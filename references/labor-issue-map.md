# 劳动合同争议分析路由

本文件提供分析提示，不替代现行法律核验。每项请求都要拆成独立要件，并根据用户立场分别检查有利证据、反证和举证缺口。

| 争议类型 | 常见待证事实 | 常见证据线索 | 重点举证风险 |
|---|---|---|---|
| 劳动关系确认 | 主体、管理从属、持续提供劳动、报酬支付 | 合同、工资流水、工牌、考勤、工作指令、社保记录 | 名称为劳务或合作不当然决定性质；检查实际履行 |
| 合同订立与效力 | 签订时间、期限、签字盖章、真实意思、规章告知 | 劳动合同原件、签收记录、电子签约日志、制度培训记录 | 单方模板不能证明已签署或已送达 |
| 工资拖欠 | 工资标准、支付周期、已付金额、欠付期间 | 合同、工资条、银行流水、个税记录、财务台账 | 区分工资、报销、奖金和一次性款项；核对金额与月份 |
| 加班工资 | 加班事实、审批制度、工作必要性、调休或支付 | 考勤、排班、审批、工作消息、门禁、系统日志、工资表 | 单一截图可能缺上下文；说明记录控制关系 |
| 解除或终止 | 解除主体、理由、时间、通知到达、事实依据、程序 | 解除通知、送达记录、违纪材料、制度、工会程序、离职交接 | 口头通知、理由事后变更、制度未公示和形成时间是高风险点 |
| 补偿或赔偿 | 解除性质、工作年限、工资基数、已付款 | 入职材料、工资记录、解除文件、补偿协议、付款凭证 | 第一版只审计证明链，不计算金额 |
| 竞业限制 | 适格主体、范围期限、补偿支付、竞业行为、违约责任 | 协议、岗位职责、补偿流水、工商信息、任职材料 | 不得仅凭同业任职推定接触秘密或实际竞争 |

## 状态判定

- `完整覆盖`：材料覆盖待证事实核心环节且未发现未解释的关键冲突；不等于必然采信。
- `部分覆盖`：有相关材料，但身份、时间、来源、上下文或关键环节不足。
- `缺失`：当前材料未覆盖待证事实。
- `相互冲突`：两项以上陈述或材料在关键字段上不能同时成立。
- `待确认`：可读性、OCR、页码、主体对应或法律版本不足以稳定判断。

工伤、社保行政征缴、集体劳动争议、纯劳务合同及刑事取证不在第一版实体规则内，需在报告中标明范围外事项。
